# HuaXinjing_servo 脚本说明

本文档说明 `src/uarm/scripts/Uarm_teleop/HuaXinjing_servo/` 下主要脚本的用途、运行方法、发布的话题。

## 准备工作

- 确保已编译并 source 工作区：
	```bash
	source devel/setup.bash
	```
- 确保脚本有可执行权限（如 rosrun 报找不到脚本）：
	```bash
	chmod +x src/uarm/scripts/Uarm_teleop/HuaXinjing_servo/*.py
	```
- 串口设备权限问题（若无法打开串口）：
	```bash
	sudo chmod 666 /dev/ttyUSB0
	# 或使用 udev 规则持久化权限设置
	```

## 常用 SDK 接口（fashionstar_uart_sdk）

- `query_current(id)`：读取指定 ID 的电流（单位 A）。
- `query_servo_angle(id)`：读取指定 ID 的角度（单位 deg）。
- `set_servo_angle(id, angle)`：在角度模式下设置目标角度（等价于“自锁”）。
- `set_damping(id, power_mW)`：设置舵机阻尼功率（mW），用于阻尼模式。

## 脚本概览与使用方法

- `hxj_test_convert_cur_to_tor.py`
	- 作用：读取单个舵机电流，计算估算扭矩并发布两个话题：`/servo_currents` 和 `/servo_torques`。
	- 默认以 ROS 节点方式运行（无需额外参数）。
	- 参数（可用 rosparam 或命令行 `_param:=value` 覆盖）：
		- `~port` (默认 `/dev/ttyUSB0`)
		- `~baudrate` (默认 `115200`)
		- `~servo_id` (默认 `0`)
		- `~num_servos` (默认 `7`)：输出数组长度
		- `~kt` (扭矩常数，默认约 `2.45/3.0` Nm/A)
		- `~idle_current` (空载电流，默认 `0.03` A)
		- `~interval` (发布间隔，秒)
	- 发布格式：`Float64MultiArray`，数组长度为 `~num_servos`，仅在索引 `servo_id` 位置有值，其他位置为 `0.0`。
	- 运行示例：
		```bash
		rosrun uarm hxj_test_convert_cur_to_tor.py
		rostopic echo /servo_currents
		rostopic echo /servo_torques
		```

- `hxj_test_angle_current.py`
	- 作用：切换舵机到角度模式，持续读取角度与电流并发布（已改为 ROS 节点风格）。
	- 发布话题：`/servo_angles`（Float64MultiArray）、`/servo_currents`（Float64MultiArray）。
	- 参数：`~port`, `~baudrate`, `~servo_ids`（列表，可指定多个 id），`~num_servos`, `~rate`。
	- 运行示例：
		```bash
		rosrun uarm hxj_test_angle_current.py
		rostopic echo /servo_angles
		rostopic echo /servo_currents
		```

- `hxj_servo_reader_fixed.py`
	- 作用：按固定采样速率读取指定舵机子集角度并平滑插值后发布 `/servo_angles`。
	- 参数及发布与 `hxj_test_angle_current.py` 类似，常用于仿真/上层节点订阅角度数据。

- `hxj_servo_reader.py` / `hxj_servo_reader_zero_reset.py`
	- 作用：早期版本的角度读取脚本，功能与 `hxj_servo_reader_fixed.py` 相近，`zero_reset` 版本会在启动时做额外的零点复位逻辑。

- `hxj_test_gravity_compensation_angle.py`
	- 作用：自适应重力补偿（基于角度变化调整阻尼功率），用于通过阻尼抵消重力导致的下坠。
	- 使用示例（直接运行）：
		```bash
		rosrun uarm hxj_test_gravity_compensation_angle.py
		```
	- 参数：`--id`, `--base-power`, `--angle-gain`, `--max-power`, `--interval`, `--once`。
	- 注意：脚本已增强为在初始化读取角度时进行重试处理，遇到 `SerialException` 会重试并在失败后继续（初始角度设为 0）。

- `hxj_config_servo.py`
	- 作用：舵机配置脚本，用于修改舵机参数（ID、模式、限位等），通常只在调试或生产阶段运行一次。


## 话题与消息说明

- `/servo_angles`：`std_msgs/Float64MultiArray`，位置索引对应舵机 ID，值为角度（deg）。
- `/servo_currents`：`std_msgs/Float64MultiArray`，数组索引对应舵机 ID，值为负载电流（A）。
- `/servo_torques`：`std_msgs/Float64MultiArray`，数组索引对应舵机 ID，值为估算扭矩（Nm）。

说明：多数脚本为了兼容多舵机系统采用数组发布，数组长度由 `~num_servos` 决定；若只读取单个 `servo_id`，脚本会把值填到对应索引，其它索引为 `0.0`。


## 例子：查看电流与扭矩

1. 启动节点：
	 ```bash
	 rosrun uarm hxj_test_convert_cur_to_tor.py
	 ```
2. 打印话题：
	 ```bash
	 rostopic echo /servo_currents
	 rostopic echo /servo_torques
	 ```
